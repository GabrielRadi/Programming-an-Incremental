# Programming-an-Incremental
repositorio do jogo "programando um incremental" para o projeto de extensão da Universidade Unifil

scripts atuais:
game_data.gd -> classe que armazena todas as variaveis do jogo, money, preço de itens, estatisticas etc
global.gd -> classe que faz o save/load do jogo além de gerar os ganhos offline
botao_principal.gd -> objeto botão principal do jogo que gera o dinheiro
control.gd -> classe que serve como a tela principal do jogo, onde todos os scripts de botões de compra estão localizados
