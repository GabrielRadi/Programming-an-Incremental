# Programming-an-Incremental
repositorio do jogo "programando um incremental" para o projeto de extensão da Universidade Unifil

scripts atuais: <br>
(ignorem os scripts contendo ".uid" no final, eles são os scripts identificadores do Godot para cada um dos scripts abaixo <br>

game_data.gd -> classe que armazena todas as variaveis do jogo, money, preço de itens, estatisticas etc <br>
global.gd -> classe que faz o save/load do jogo além de gerar os ganhos offline <br>
botao_principal.gd -> objeto botão principal do jogo que gera o dinheiro <br>
control.gd -> classe que serve como a tela principal do jogo, onde todos os scripts de botões de compra estão localizados <br>
